 📈 StockSurvivor

**StockSurvivor** is a stock market-focused web application designed to help users explore stock market information, understand market movements, and make more informed financial decisions through a user-friendly interface.

 ✨ Features

- 📊 **Stock Market Dashboard** – A centralized interface for exploring stock market information.

- 🔍 **Stock Exploration** – Find and explore relevant stock information.

## 🚀 Getting Started

Follow these instructions to run StockSurvivor locally.

### 1. Clone the Repository

```bash
git clone https://github.com/hetviipanchal/StockSurvivor-.git
```

### 2. Navigate to the Project Directory

```bash
cd StockSurvivor-
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```

### 5. Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
